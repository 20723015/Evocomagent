# 并夕夕 七天无理由商品清单

## 一、支持七天无理由的商品

1. **服装鞋帽**：未洗涤、吊牌齐全、不影响二次销售（内衣/泳装拆封除外，见《服装鞋帽类目规则》）。
2. **图书**：未拆塑封（见《图书文教类目规则》）。
3. **家纺**：未拆洗（见《家居家纺类目规则》）。
4. **3C 数码**：未激活（手机未联网、电脑未开机联网、耳机未配对，见《3C数码类目规则》）。
5. **运动户外**：未使用、吊牌齐全（户外鞋鞋底无磨损）。
6. **美妆个护**：未拆封、外包装完好（礼盒拆开视同拆封）。
7. **母婴用品**：奶粉/辅食未开封（需完整外包装）；纸尿裤未拆封。
8. **珠宝**：未佩戴、标签齐全（黄金饰品除外，见《珠宝钟表类目规则》）。

## 二、不支持七天无理由的商品

1. **个人定制类**：刻字、刻名、定制尺寸、图案定制（见《生鲜与定制商品规则》）。
2. **鲜活易腐**：水果、海鲜、生鲜冷链。
3. **数字化商品**：已激活的软件序列号、电子卡券、电子书、课程（见《图书文教类目规则》）。
4. **拆封影响健康安全**：化妆品、护肤品、内衣、泳装、隐形眼镜（已拆封）。
5. **贵金属**：黄金饰品、投资金条（按回购规则，见《珠宝钟表类目规则》）。
6. **临期特惠品**：剩余保质期 < 1/3 的食品（见《食品饮料类目规则》）。
7. **已确认的定制/服务类**：装修服务、课程报名、赛事报名。

## 三、边界判定

1. 套装中部分可退部分不可退：可退部分按比例退款（赠品需一并退回，见《大促活动总规则》）。
2. 商品页面标注「不支持七天无理由」但已勾选平台协议说明的，以页面为准。
3. 二手商品：按《二手闲置交易规则》执行（成色描述不符可退）。

## 四、申请时限与条件

1. 自签收之日起 7 天内（含第 7 天）申请，超期后仅质量问题可退（见《退换货政策》）。
2. 退回时需商品本体、吊牌、包装、配件、赠品齐全。
3. 无理由退货运费买家承担（运费险可理赔，见《退货运费承担方判定规则》）。
