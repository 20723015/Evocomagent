# 并夕夕 上门取件服务说明

## 一、服务内容

1. 上门取件：快递员上门揽收退货包裹，覆盖顺丰/圆通/京东物流，全国大部分区域。
2. 服务时间：每日 9:00-20:00 可预约，下单后 1-2 小时内上门（高峰时段最长 4 小时）。
3. 取件范围：单件 ≤ 20kg 标准包裹；超重/超尺寸走大件物流（见《退货运费计算标准》）。

## 二、费用与减免

| 用户类型 | 上门取件运费 |
| --- | --- |
| 普通用户 | 12 元起（按重量/距离） |
| 白银会员 | 运费减免 50% |
| 黄金会员 | 免费 |
| 钻石会员 | 免费 |
| PRO 会员 | 每月 4 张免运费券（8 元/张，超出部分自理） |

1. 质量问题退货：运费平台承担，上门取件免费。
2. 七天无理由退货：运费买家承担，从退款金额中扣除。
3. 运费险理赔独立进行（见《运费险细则》），不重复减免。

## 三、取件流程

1. 申请售后 → 选择「上门取件」→ 预约时间 → 快递员上门揽收。
2. 寄件前请打包好商品（保留原包装、配件、赠品），取件员检查后开具面单。
3. 面单拍照留存：作为运费险理赔与责任判定的凭证。

## 四、异常处理

1. 快递员爽约/超时：可改约或取消，24 小时内联系客服催单。
2. 取件后物流停滞：超 3 天无轨迹可发起物流催单（见《物流异常与投诉处理》）。
3. 上门取件不支持的地区：可自行寄回，运费按面单金额计算。

## 五、与其他权益的关系

- 与「运费险」叠加时优先走免费取件，不重复赔付（见《运费险细则》）。
- 与「无忧退」（钻石会员一年 4 次）叠加：无忧退直接退款，运费全免。
- 换货同样支持上门取件，费用按责任判定（见《退货运费承担方判定规则》）。
