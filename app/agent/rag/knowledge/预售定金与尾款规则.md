# 并夕夕 预售定金与尾款规则

## 一、预售流程

1. 预售分两阶段：支付定金锁定优惠价 → 尾款期内支付尾款完成订单。
2. 定金金额：一般为商品价格的 10%-30%，页面明示；定金支付后不可修改商品规格。
3. 尾款期：商品页公示时间（通常 1-7 天），超期未付尾款定金不退（定金单独处理见 §三）。

## 二、定金与尾款规则

1. **定金退还**：定金支付后 **7 天内**可无理由退还（见《优惠券与促销规则》）。
2. 超 7 天未支付尾款：定金按「逾期未付」处理，可申请退还但需商家同意（商家不同意则按定金规则没收）。
3. 尾款支付后：预售订单按正常订单履约，发货时间以公示为准（不适用 48h 出货承诺）。
4. 尾款阶段可用券：以尾款实付金额计算门槛，定金部分不可用券。

## 三、退款规则

1. 尾款支付前退定金：定金原路退回，7 天内无理由；超期需商家同意。
2. 尾款支付后退全款：定金+尾款全额退还，已用券按《优惠券退回与补发规则》退回。
3. 部分退款：按实际支付比例折算，定金与尾款按比例退回。
4. 商家原因（缺货/发不出）取消预售订单：定金+尾款全额退还，另赔偿实付金额 5%（最低 5 元）。

## 四、价保与发货

1. 预售订单价保：以尾款实付金额为比价基数，价保期按常规（7/15/30 天）执行（见《大促价保特别条款》）。
2. 预售发货：按商品页公示发货时间，大促期间按《大促活动总规则》放宽 7 天。
3. 预售商品不支持「未发货 72 小时催单」规则。

## 五、常见问题

- **Q：定金能退吗？** A：7 天内无理由可退；超 7 天需商家同意（恶意占名额会被风控）。
- **Q：忘付尾款怎么办？** A：定金 7 天内可退，超期联系商家协商；尾款期过订单关闭。
- **Q：预售发货慢正常吗？** A：正常，发货时间以页面公示为准。
