# 并夕夕 优惠券退回与补发规则

## 一、退回场景

| 场景 | 退回规则 |
| --- | --- |
| 取消订单（未发货） | 已用券在订单关闭后 **24 小时内**退回，有效期原样保留 |
| 全额退款（已发货退货） | 券随退款一并退回，有效期顺延 7 天（仅一次） |
| 部分退款 | 券按退款金额占比折算退回，退回券有效期顺延 7 天 |
| 订单低于券门槛退款 | 系统优先退券不退现金差额（见《品类券适用范围细则》） |
| 商家取消/关闭订单 | 券立即退回，有效期原样保留 |

## 二、退回券的使用限制

1. 退回券保持原券面条件（门槛/类目/有效期顺延后可用），不可拆分、不可转让。
2. 退回券叠加规则不变：每单仍为 1 平台券 + 1 店铺券（见《优惠券与促销规则》）。
3. 已过期的券退款时不退回（过期券无价值，按退款金额折算现金退还）。

## 三、补发规则

1. 平台原因导致券未到账/被误扣：核实后补发同面额同门槛券（有效期 7 天）。
2. 系统故障导致用券失败：订单完成后 48 小时内补发原券。
3. 活动规则中承诺的「回血券」（如大促买返）按活动页公示时间发放，超时可催单。

## 四、不补发情形

- 用户自行过期、手动删除、误操作兑换的券：不补发。
- 直播间当场券、闪购专属券等场景券：过期不补（见《直播与限时活动规则》）。
- 优惠券被风控判定异常（批量领券/外挂）：冻结不补。

## 五、常见问题

- **Q：退款后券什么时候回来？** A：取消订单 24 小时内；退货退款后按流程退回，顺延 7 天。
- **Q：退回券还能用吗？** A：能，保持原门槛，有效期顺延（仅一次）。
- **Q：券过期了退款还有吗？** A：过期券不退回，按实付金额折算退款。
