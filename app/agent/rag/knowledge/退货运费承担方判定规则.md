# 并夕夕 退货运费承担方判定规则

## 一、判定总原则

1. 退货运费由**过错方**承担；无法判定过错方时，按「谁受益谁承担」处理。
2. 运费险（见《运费险细则》）是**补充保障**，先判责任方、再走保险理赔，两者不重复。
3. 上门取件运费 12 元起（见《退换货政策》），责任方承担后从退款中扣除或平台垫付。

## 二、责任判定表

| 退货场景 | 运费承担方 | 依据 |
| --- | --- | --- |
| 七天无理由退货 | **买家** | 《退换货政策》 |
| 质量问题退货 | **平台/商家** | 《退换货政策》 |
| 商品错发/漏发 | 商家（运费全承担） | 《退换货政策》 |
| 物流破损拒收 | 承运方（平台先行赔付） | 《价保与赔付规则》 |
| 无理由退货但商品影响二次销售 | 买家 + 拒退或折价 | 《退换货政策》 |
| 质量问题但已使用/激活 | 商家承担（按质量问题） | 《拆封商品退换判定标准》 |

## 三、运费险与责任方的关系

1. 买家承担运费（无理由退）：运费险可理赔，理赔上限 25 元（商家赠险 40 元，见《运费险商家版规则》）。
2. 商家/平台承担运费：**不触发运费险**（运费已由责任方承担，保险无损失可赔）。
3. 实际运费超出保险上限部分：无理由退货由买家自担，质量问题由商家承担。
4. 运费险理赔后商家仍可向承运方追偿，买家无需参与。

## 四、特殊场景

1. **跨境退货**：无理由退货国际运费由买家承担（见《跨境退货特别流程》）；质量问题平台承担。
2. **换货**：质量问题换货运费平台承担；无理由换货买家承担（部分类目支持免运费换货，以页面为准）。
3. **拒收**：拒收产生的退回运费由责任方承担——商品质量问题拒收，运费商家承担；无理由拒收，运费买家承担。
4. **多包裹订单**：部分退货时各包裹运费分别按上述规则判定。

## 五、争议处理

- 运费责任争议：申请平台介入，商家 48 小时内响应，仲裁 3-7 个工作日（见《纠纷仲裁与举报规则》）。
- 判定后运费差额（买家已垫付）在退款到账后 1-3 个工作日内原路退回或从退款中抵扣。
