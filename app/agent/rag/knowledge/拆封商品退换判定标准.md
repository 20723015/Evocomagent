# 并夕夕 拆封商品退换判定标准

## 一、判定总原则

1. 是否支持退换取决于**拆封是否影响二次销售或人身安全**，而非单纯「是否拆封」。
2. 三类判定：可退（拆封不影响再售）、视同激活/使用（不可无理由退）、实质使用（仅质量问题可退）。
3. 各品类细则优先于本通则（如《美妆个护类目规则》《3C数码类目规则》）。

## 二、拆封判定标准

1. **外包装破损（快递运输）**：不影响商品本体二次销售，仍可七天无理由退；运输破损按《价保与赔付规则》理赔。
2. **商品塑封/密封贴拆开**：视商品而定——食品/药品/化妆品拆封视同启用，不可无理由退。
3. **一次性封条破坏**：电子产品封条破坏视同激活（见《3C数码类目规则》），不支持无理由退。
4. **试穿/试戴**：服装试穿后吊牌齐全、无污渍可退；鞋底明显磨损、珠宝佩戴痕迹视为使用。

## 三、视同激活/使用的判定

| 情形 | 判定 | 依据 |
| --- | --- | --- |
| 手机/平板联网激活 | 视同激活 | 《3C数码类目规则》 |
| 耳机/手表蓝牙配对 | 视同激活 | 《3C数码类目规则》 |
| 化妆品/护肤品启封使用 | 视同使用 | 《美妆个护类目规则》 |
| 内衣/泳装试穿 | 视同使用（卫生） | 《服装鞋帽类目规则》《运动户外类目规则》 |
| 电子书/课程开始阅读学习 | 视同使用 | 《图书文教类目规则》 |
| 卡券/充值码刮开兑换 | 视同激活 | 《礼品卡与储值卡》 |

## 四、仅质量问题可退的判定

1. 已使用/已激活商品出现质量问题：凭举证（照片/视频/检测报告）走 15 天质量问题退换货（见《退换货政策》）。
2. 拆封后发现缺件/错发：不影响判定为质量/物流问题，运费平台承担。
3. 拆封后商品外观轻微瑕疵（不影响使用）：由商家承担退换运费或折价补偿，买家自选。

## 五、争议处理

- 商家与买家对「是否影响二次销售」判定不一致时，申请平台介入仲裁（见《纠纷仲裁与举报规则》）。
- 判定以平台仲裁记录为准，同一商品同一问题不可重复申诉。
- 恶意利用判定规则反复拆封退货的账号，取消极速退款资格并风控降权。
