# 并夕夕 官方延保服务范围对照

## 一、随机保修与加购延保

1. **随机保修**：随商品附带的厂家保修，3C/家电整机 1 年（部分品牌 2 年），见《售后维修与延保》。
2. **加购延保**：购买商品时随单购买的付费延保，1 年延保 = 整机保修 + 1 年。
3. 两者叠加：加购 2 年延保后，总保修 = 随机保修 1 年 + 延保 2 年 = **3 年**。

## 二、覆盖范围对照

| 项目 | 随机保修 | 加购延保 |
| --- | --- | --- |
| 非人为硬件故障 | 覆盖 | 覆盖 |
| 人为损坏（进水/摔裂/私拆） | 不覆盖 | **不覆盖** |
| 易耗件（电池/数据线/贴膜） | 不覆盖 | 不覆盖 |
| 屏幕碎屏 | 不覆盖 | **覆盖 1 次/年**（加购版专属） |
| 免费上门维修 | 品牌方决定 | 加购版含 1 次 |
| 备用机服务 | 无 | 维修超 7 个工作日提供 |

## 三、购买与生效

1. 购买时机：仅随单购买，收货后不可补购（与《售后维修与延保》一致）。
2. 生效时间：延保自随机保修到期次日生效，与随机保修无缝衔接。
3. 价格：1 年延保按商品价格 3%-8% 定价，页面明示。

## 四、索赔流程

1. 报修入口：「我的订单 → 申请售后 → 延保理赔」，上传故障视频/照片。
2. 理赔判定：品牌方授权售后检测，非人为损坏即受理；检测周期 3-7 个工作日。
3. 维修方式：寄修或上门（加购版含 1 次免费上门），修好原路寄回。
4. 拒赔申诉：对拒赔有异议可申请平台复核，7 个工作日内反馈。

## 五、注意事项

- 延保权益随商品转让：二手转卖后延保仍随序列号生效（需在平台登记变更）。
- 延保不可单独退款；订单全额退货时延保费随订单一并退回。
- 官方延保与品牌官方延保服务条款（平台外）互不冲突，理赔按先到先得执行。
