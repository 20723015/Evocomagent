# 并夕夕 退款到账时效分档表

## 一、按支付渠道分档

| 支付渠道 | 原路退回时效 |
| --- | --- |
| 微信支付 | 1-3 个工作日 |
| 支付宝 | 1-3 个工作日 |
| 银行卡（储蓄卡） | 3-7 个工作日 |
| 花呗/信用卡分期 | 当期账单已出 → 抵扣下期账单 |
| 账户余额（礼品卡） | 实时到账 |

## 二、按退款类型分档

| 退款类型 | 时效 |
| --- | --- |
| 未发货自动退款 | 系统秒退（1-3 个工作日到账） |
| 极速退款（≤200 元） | 平台垫付，1-3 个工作日到账 |
| 已发货未签收退款 | 商家 24 小时内响应，超时自动同意 |
| 质量问题退款 | 仓库签收质检后 1-3 个工作日 |
| 拒收退款 | 仓库签收后 5-7 个工作日 |
| 大额订单（≥5000 元） | 人工审核，3-7 个工作日（见《大额订单退款时效》） |

## 三、影响因素

1. 银行清算时间：周五晚至周日发起的银行卡退款，顺延至下周一处理。
2. 平台风控审核：异常退款（频繁/大额/新账号）会延长审核 1-2 个工作日。
3. 商家申诉：商家对退款有异议提交反证后，退款暂停，仲裁 3-7 个工作日。

## 四、查询与异常

1. 退款进度：「我的订单 → 退款详情」实时查看各阶段时间戳。
2. 超时未到账：凭退款成功页截图联系客服，48 小时内核查原路退回。
3. 原支付渠道失效（卡注销）：联系客服改退至其他银行卡或账户余额。

## 五、与《极速退款规则》的关系

- 极速退款仅覆盖信用良好买家的 ≤200 元订单（见《极速退款规则》）。
- 超过 200 元部分走普通流程，按本表渠道时效到账。
- 垫付资金从商家保证金扣除，不影响买家到账速度。
