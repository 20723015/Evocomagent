# 并夕夕 纠纷仲裁与举报规则

## 一、纠纷类型与入口

1. 交易纠纷（商品/物流/售后）可在「我的订单 → 申请售后 → 平台介入」发起，商家 48 小时内响应。
2. 商家超时未处理自动转入平台仲裁，仲裁周期 3-7 个工作日。
3. 纠纷升级：对仲裁结果不满可申请「专员复核」（见《物流异常与投诉处理》）。

## 二、仲裁判定

1. 举证规则：谁主张谁举证，图片/视频/凭证均可作为证据。
2. 商品描述不符 → 商家责；物流破损 → 承运方责（平台先行赔付）；售后拖延 → 商家责。
3. 判定结果支持「先行退款」再向商家追偿，避免买家久等。

## 三、举报类型

1. 假货/盗版：凭鉴定结果举报，核实后假一赔三（见《价保与赔付规则》）。
2. 虚假宣传/好评返现：截图举报，核实后下架并处罚。
3. 违规行为（刷单/售假/售未成年人禁售品）：均可举报，举报入口「商品页 → 举报」。

## 四、处罚与申诉

- 商家违规按情节：警告 → 限流 → 下架 → 冻结店铺。
- 商家对处罚可在 7 天内申诉，提交反证材料（进货凭证/授权书）。
