# 并夕夕 支付与账户安全

## 一、支付方式

1. 支持微信支付、支付宝、银联快捷支付、Apple Pay、花呗分期（3/6/12 期）、银行卡支付。
2. 暂不支持货到付款、境外信用卡、数字人民币（筹备中）。
3. 大额订单（单笔 ≥ 5000 元）部分支付方式可能触发短信验证。

## 二、账户安全

1. **登录保护**：异地登录、新设备登录触发短信/人脸验证。
2. **支付密码**：修改需原支付密码+手机验证码双重验证；连续输错 5 次锁定 30 分钟。
3. **设备管理**：可在「设置 → 账户安全 → 登录设备」查看并下线陌生设备。
4. **未成年人保护**：未成年人实名账户默认开启消费限额（单日 ≤ 500 元）。

## 三、防诈骗提醒

- 平台客服**不会**索要支付密码、短信验证码，也不会要求转账到个人账户。
- 任何"退款到个人卡/刷单返利/解冻保证金"均为诈骗，请直接举报。
- 疑似被骗：第一时间修改密码+解绑支付方式，联系客服冻结账户并报警。

## 四、异常交易

- 疑似盗刷：冻结账户 → 提供报警回执 → 平台协助资金追讨，核实后 7 个工作日内处理。
- 重复扣款：凭扣款截图在 48 小时内申请原路退回。
- 支付成功未识别：5 分钟内自动同步，超 30 分钟联系客服（见 FAQ）。
