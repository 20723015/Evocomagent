# 工具结果结构化精简计划（记忆/摘要转录层 · 半天）

> 目标：`extraction.py` 与 `summarizer.py` 两处 `[:200]` 前缀截断升级为**按工具字段投影**——
> 同样的 200 字预算覆盖十倍有效信息，且两处共用单一实现（`app/agent/tools/digest.py`），不再漂移。
> **明确不动**：ReAct 循环内模型看到的完整结果、会话持久化、TurnRecorder。

## 1. 新模块：`app/agent/tools/digest.py`（单一事实源）

`digest_tool_result(tool_name, content_json_str, budget=200) -> str`

**三层降级（确定性，绝不抛异常）**：
1. JSON 解析成功且工具在投影表 → 按表投影；
2. JSON 解析成功但工具不在表内（含未来新增工具）→ **通用压缩**：仅保留顶层标量字段
   （str 字段截 40 字），丢弃嵌套对象与长文本，结果截到预算；
3. 解析失败（非 JSON）→ 旧版前缀截断 `content[:budget]`。

任何内部异常 → 落到第 3 层。`json.dumps(..., ensure_ascii=False, sort_keys=True)` 保证确定性。

## 2. 投影表（基于真实返回结构，已逐一核实）

| 工具 | 保留（真实字段） | 说明 |
|------|------------------|------|
| `query_order` | `order.order_id / status / total / tracking_number` + `items[0].name`（若有） | 嵌套在 `order` 下 |
| `list_user_orders` | 每项 `order_id / status / items_summary`；≤10 项、每项截 60 字，超限尾部 `…另有N单` | 相关订单在第 8 个也不被切掉 |
| `query_logistics` | `logistics.tracking_number / carrier / status` + `events[-1].time/description`（各截 40） | 最新状态优先 |
| `query_product` | `products[]` 前 2 项：`name / price / stock / product_id`（＞2 项尾部 `…另有N项`） | ⚠ 字段在 `products[]` 列表内，非顶层 |
| `search_knowledge` | `命中N篇: doc1、doc2、doc3`（≤5 个 doc 名，去重） | 来源名可产出"咨询过退换货政策"类事实 |
| `apply_refund` | `success / status` + `message` 或 `error` 截 60 字 | 状态语义必须保留 |
| `recall_user_memory` | 原样（本身已短，通常 <200） | |
| `load_skill` | success 且 skill_name → `已加载技能: {name}（指令略）`；否则走通用压缩 | 正文 markdown 无贡献 |

⚠ 与初稿的两处修正（以真实返回为准）：
- `query_product`：字段在 `products[]` 列表内，不是顶层标量；
- 物流字段名是 `carrier`（不是 `courier`）。

**预算语义**：200 字是每条 tool 消息总预算——投影后仍超 200 则截到 200（带 `…`）；
token 成本零回归；剩余预算不复用。

**执行修正（钉死事实时发现计划矛盾）**：`list_user_orders` 的「每项截 60」与「≤200 总预算」
与「第 8 项保留」数学上不可兼得（10 × 60 = 600）。落地语义为**逐档降级**：摘要按
60→30→16→8→0 字符档逐级压缩（0 档=放弃摘要段），每项 `order_id + status` 恒保，
尾标 `…另有N单` 恒保（0 档分隔符收紧为 `|`）；相关订单在任何位置都不会被再切掉。

## 3. 接线与格式

- tool 行统一 `[工具结果] {tool_name} {digest}`——工具名从 `tool_call_id` 反查
  assistant 调用行（`renders` 层共享 `tool_call_name_map`），流式/截断场景下 tool 行自足；
- 调用行渲染差异（提取不带参数/摘要带参数）维持现状；
- 配置：`tool_digest_enabled=True`（总开关，False 整体回退旧格式）、`tool_digest_budget_chars=200`。

## 4. 验收测试（无网络）

逐工具投影正确性 / list_user_orders 第 8 项动机场景 / 全部输出 ≤200 / 三层降级 /
双接线一致（同输入同 tool 行）/ 确定性 / 开关回退 golden 比对 / knowledge 去重 ≤5。

## 5. 风险与应对

投影只增不删（评审可加字段）、未知工具走通用压缩零登记即可用、总开关一键回退。
