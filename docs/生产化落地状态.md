## 二、怎么跑

```bash
# 单测（无网络）
python -m pytest

# 评估数据门禁（无网络，CI 同款）
python -m app.scripts.check_eval_dataset

# CLI（默认用户 u1；无 OpenAI key 时工具/检索会降级报错，属预期）
python main.py --user u1

# API（Redis 未启动自动降级本地文件）
python -m uvicorn app.server.main:app --port 8000
#   POST /v1/chat {"user_id":"u1","session_id":"s1","message":"你好"}
#   GET  /v1/chat/stream?user_id=u1&message=你好   （SSE）
#   GET  /metrics  /healthz  /readyz  /docs

# 知识审核后台
python -m uvicorn app.review.webapp:create_review_app --factory --port 8001

# 离线评估（需 OPENAI_API_KEY）
python -m app.scripts.run_eval --no-judge
```

## 三、外部条件（未在本机验证/需要联调的部分）

- **OpenAI/Embedding API Key**：所有 LLM 路径（真实对话、评估、检索）需要；
  本机整套验证用的是 conftest FakeChatClient / FakeEmbedder。
- **Redis**：保留并发角色（分布式锁 + 限流计数 + 会话热缓存），生产必须
  （`REDIS_REQUIRED=true` 时连不上启动即失败）；本机未装 Redis，验证经
  fakeredis + 本地文件降级路径。有 Docker 的环境可
  `docker run -d -p 6379:6379 redis`（本机按约定未装 Docker，未执行）。
- **MySQL / ES**（阶段八）：`DB_URL` 配置即启用 SQL 正本（本地可用
  `sqlite:///app/sessions/ecom.sqlite` 走同一条行式追加路径，已全量单测）；
  `ES_URL` + `RAG_BACKEND=es` 即启用 ES 检索与 message_search。
  两者本机未装服务：SQL 经 sqlite 方言、ES 经迷你内存替身（payload 断言
  验证了 hybrid 查询结构含 match+knn+rank.rrf、alias 切换/建模校验/探针、
  消息端点归属围栏与降级）；生产建库跑 `deploy/sql/001_init.sql`，
  接真实 ES 后先跑 `build_kb_index --backend es` 再做一轮检索回归。
- **chromadb**：早期在 Windows 上曾出现 1.x Rust 核心崩溃（0xC0000005），
  后经环境修复（VC++ 运行时）本机已可正常跑（探针退出码 0、chroma 单测
  通过）。仓库内 chroma 单测的「子进程探针守卫」保留：若目标机 Rust 核心
  不可用会自动 skip，不影响其他用例。生产按 `settings.rag_backend` 切换，
  numpy 后端零依赖可用。
- **Docker/K8s**：按约定未安装 Docker，Dockerfile/Helm/看板均为待构建/待发布
  状态；`deploy/README.md` 给出了连接真实集群后的完整命令。
- **真实订单/退款后端**：mock 数据 + 凭证注入点（`security/credentials.py`
  OBO 占位）就绪，后端就绪后只换实现，不动协议。

## 四、主要行为变更（对旧教学行为的影响）

1. `list_user_orders` 按 `ctx.user_id` 过滤（无 ctx 的旧直调仍返回全部）；
1. 计划 1.3 的"删除全局单例"实际落地为「生产路径零单例 + 旧路径兼容」：
   `set_memory_manager/set_skill_manager` 保留但仅服务无 ctx 的旧脚本
   （`memory_tool.py`/`skill_tool.py` 有注释说明），API/CLI 均经 ToolContext；
2. `apply_refund`：`REFUND_CONFIRMATION_REQUIRED=true` 时两段式（默认 false
   保持直退，CLI/教学不受影响）；
3. 长期记忆巩固：从「仅 close()」改为「每 N 轮增量 + 静默 30min 兜底」；
4. 检索命中块默认带来源围栏（`RETRIEVAL_FENCE_ENABLED=true` 时）；
5. 输出日志从 print 换 structlog：CLI 用 `LOG_FORMAT=console` 人类可读，
   server 用 JSON。
